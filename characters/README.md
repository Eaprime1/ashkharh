# Characters — Living Entities

This directory holds profiles for every living entity in **The Play (Existence in Motion)**.

Each character file follows the Triadic pattern:

- **STORY** — Narrative context and origin.
- **STATUS** — Current Prime Stage and Ka Pressure reading.
- **NEXT ACTION** — Immediate continuation for the character.
