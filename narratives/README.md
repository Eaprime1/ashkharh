# Narratives — Story Arcs and World Events

This directory holds the active story arcs and world-event records for **The Play (Existence in Motion)**.

Each narrative file follows the Triadic pattern:

- **STORY** — The arc's premise and narrative context.
- **STATUS** — Current progression state (Prime Stage reached, Ka Pressure level).
- **NEXT ACTION** — The immediate next scene or decision point.
