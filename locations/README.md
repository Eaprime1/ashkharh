# Locations — Play Environment Data

This directory holds data for every named place within **The Play (Existence in Motion)**.

Each location file follows the Triadic pattern:

- **STORY** — Narrative context and environmental atmosphere.
- **STATUS** — Current state of the location within the Play.
- **NEXT ACTION** — Events or entities expected to arrive or depart.
